**Контекст:** этот сайт технически сильно опережает kran365 (Astro, много «волн» полировки в истории коммитов — reading-progress bar, десктопный sticky-TOC, компонент `Sources.astro`, ролевой byline «Инженерная служба МОСКРАН-СЕРВИС»). Часть требований плейбука уже частично реализована — важно не задваивать, а достроить то, чего не хватает именно в СТАТИЧЕСКОМ HTML (AI-краулеры не выполняют JS).

Топ: нет источников (167), H2 без id (163), нет TOC (163), сущность не названа (163), нет автора (161), первое предложение не тезис (153), нет `<time>` (139), короткий intro (104), длинное первое предложение (97), нет FAQ (75).

**Важные находки ДО патча (чтобы не чинить то, что не сломано):**
- **«Нет блока источников» (167) — в основном ложное срабатывание.** У сайта уже есть `src/components/Sources.astro`, реально используется (проверено на живой странице: «Источники, проверено 12.08.2026»). geo_check.py ищет слово «источник» только в тексте `<h2>`, а этот компонент рендерит его в `<p class="srcs__head">` внутри `<aside>` — чекер его не видит. Скилл/чекер не трогала (общий файл на все 8 сайтов), фиксирую здесь как известное расхождение.
- **«Нет TOC» (163) — тоже в основном ложное срабатывание после патча.** Десктопный TOC уже существует (`<aside id="ref-toc-desktop">`), просто не `<nav>`, а geo_check ищет TOC только по тегу `nav`. Реальный TOC на странице ЕСТЬ и после патча заполнен статически.
- **«Нет автора» (161) — тоже частично ложное.** Есть `.ref-byline`: «Инженерная служба МОСКРАН-СЕРВИС · обновлено в 2026 году» — честная ролевая подпись (не выдуманный человек), просто без слов «редакция»/«автор» из словаря чекера.

**Сделано (реально, не косметика для чекера):** `scripts/geo2026-postbuild.mjs`, подключён в `package.json` → `postbuild` (после `generate-redirects`/`generate-sitemap`). Работает по собранному `dist/**/*.html`:
- `id` на каждый `<h2>` внутри `<article>` (справочник) или `<main>` (остальные типы страниц) — транслитерированный слаг, уникальность гарантирована.
- Наполняет уже существующий пустой `<aside id="ref-toc-desktop"><ol class="ref-toc__list">` реальными `<li><a href="#id">` при ≥3 H2 и снимает атрибут `hidden` — TOC работает и без JS/для краулера. Клиентский скрипт сайта при загрузке безопасно заменяет список на свой (тот же контент) — дублирования нет, конфликтов с уже написанным JS не найдено.
