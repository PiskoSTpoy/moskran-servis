Как проверить канат автокрана при замене: расчёт запаса прочности?

Автор: инженерная служба МОСКРАН-СЕРВИС опубликовано 23.10.2026 обновлено 23.10.2026 факты проверены 23.10.2026 6 мин чтения

Канат, который ставят вместо изношенного, обязан совпасть с паспортом крана по назначению, длине и диаметру и иметь сертификат изготовителя (п. 191 ФНП №461). Запас прочности проверяют расчётом по п. 193: разрывное усилие Fo из сертификата сопоставляют с наибольшим натяжением ветви S из паспорта и минимальным коэффициентом Zp. МОСКРАН-СЕРВИС просит заказчика подтвердить эти три числа до выезда крана.

Что должен подтвердить новый канат по п. 191

Новый канат сверяют с паспортом по трём параметрам — назначение, длина, диаметр, — а запас по разрывному усилию должен быть не ниже, чем положен группе режима механизма (п. 191 ФНП №461). Вторая безусловная часть требования — сертификат завода-изготовителя: канат без него на подъёмное сооружение не ставят. Для автокрана КС-55713 «Клинцы» паспорт и сертификат нужны оба: паспорт задаёт параметры, сертификат подтверждает прочность.

Канат зарубежного производства разрешён, если он подходит по назначению и технологии использования ПС, диаметр равен диаметру заменяемого, а коэффициент использования по разрывному усилию не ниже нормативного для группы механизма. Заменять канат крестовой свивки на канат односторонней свивки запрещено. МОСКРАН-СЕРВИС проверяет тип свивки по сертификату раньше, чем сравнивает диаметры, потому что ошибка в свивке не исправляется расчётом. Браковку каната в работе разбирает справка о браковке канатов.

Расчёт запаса по п. 193

Соответствие коэффициента использования выбранного каната проверяют расчётом по формуле п. 193 ФНП №461, в которую входят три величины. Fo — разрывное усилие каната в целом в ньютонах по сертификату или свидетельству об испытании. Zp — минимальный коэффициент использования (запас прочности) из таблицы приложения №1 в зависимости от группы классификации механизма. S — наибольшее натяжение ветви каната в ньютонах, указанное в паспорте крана. Смысл проверки: отношение Fo к S не должно быть меньше Zp.

Когда сертификат даёт только сумму разрывных усилий отдельных проволок, Fo получают умножением этой суммы на 0,83 (п. 193). МОСКРАН-СЕРВИС напоминает: коэффициент 0,83 применяют только к суммарному усилию проволок, а цифру «в целом» из сертификата умножать на него нельзя.

Пример с условными числами (арифметика, а не данные конкретного крана). Пусть S по паспорту равно 20 000 Н, механизм подъёма относится к группе M5, канат подвижный: Zp равно 4,50, значит Fo должно быть не меньше 90 000 Н. Сертификат даёт суммарное усилие проволок 110 000 Н: 110 000 × 0,83 = 91 300 Н, канат проходит. Для группы M6 (Zp = 5,60) требовалось бы не менее 112 000 Н, и тот же канат не подошёл бы.

Значения Zp из таблицы 4 приложения №1

Таблица 4 приложения №1 к ФНП №461 задаёт минимальные значения Zp отдельно для подвижных и неподвижных канатов в зависимости от группы классификации механизма M1–M8. Группу берут из паспорта ПС; если её там нет, определяют расчётом по приложению №4. МОСКРАН-СЕРВИС при подготовке замены каната на КС-65713-1 «Галичанин» первым делом выписывает группу механизма из паспорта.

Что делают после замены или перепасовки

Замена грузового, стрелового или любого другого каната и любая перепасовка заканчиваются двумя действиями (п. 191 ФНП №461). Сначала смотрят, верно ли канат заведён в полиспаст и надёжно ли закреплены концы. Затем его обтягивают грузом, равным номинальной грузоподъёмности по паспорту. Результат вносит в паспорт инженерно-технический работник, который отвечает за исправное состояние крана. МОСКРАН-СЕРВИС не выпускает автокран на объект, пока запись в паспорте крана не сделана.

Крепление каната при замене должно соответствовать ранее принятой конструкции (п. 192 ФНП №461): другой тип заделки конца без согласованного решения недопустим. Цепи на ПС подчиняются тем же принципам (п. 195): сертификат, марка и разрывное усилие по паспорту, коэффициент запаса при замене пластинчатых цепей не менее 3 для групп M1–M2 и не менее 5 для остальных, сварных грузовых — не менее 3 для M1–M2, не менее 6 на гладком барабане и не менее 8 для калиброванных цепей на звёздочке.

Коротко: замена каната по пп. 191–193

  • Новый канат должен совпасть с паспортом по назначению, длине, диаметру и иметь сертификат изготовителя (п. 191 ФНП №461).
  • Запас проверяют расчётом: Fo из сертификата, S из паспорта, Zp из таблицы 4 приложения №1; отношение Fo/S не ниже Zp (п. 193).
  • Суммарное усилие проволок умножают на 0,83, чтобы получить Fo (п. 193).
  • После замены — проверка запасовки, обтяжка паспортным грузом и запись ИТР в паспорте; МОСКРАН-СЕРВИС не выпускает кран без неё.

Частые вопросы

Можно ли заменить канат крестовой свивки на канат односторонней свивки?

Нет. Пункт 191 ФНП №461 прямо запрещает заменять стальные канаты крестовой свивки на канаты односторонней свивки. Тип свивки проверяют по сертификату до закупки, потому что расчёт запаса прочности эту ошибку не компенсирует.

Что делать, если в паспорте автокрана не указана группа механизма?

Группу классификации механизма определяют расчётом по приложению №4 к ФНП №461: по классу использования и режиму нагружения (п. 193). Полученную группу затем используют для выбора Zp в таблице 4 приложения №1.

Как получить Fo, если в сертификате указано суммарное усилие проволок?

Суммарное разрывное усилие проволок умножают на 0,83 (п. 193 ФНП №461). Например, 110 000 Н даёт Fo = 91 300 Н. Если в сертификате дано усилие каната в целом, коэффициент 0,83 не применяют.

Что обязательно сделать после замены каната на автокране?

Проверить запасовку и крепление концов, обтянуть канат грузом по паспортной номинальной грузоподъёмности и записать это в паспорт (п. 191). Запись делает инженерно-технический работник, ответственный за содержание ПС в работоспособном состоянии.

Годится ли импортный канат для замены?

Да, если он подходит по назначению и технологии использования, диаметр равен диаметру заменяемого, а коэффициент использования по разрывному усилию не ниже нормативного для группы механизма (п. 191 ФНП №461). Сертификат нужен и на импортный канат.
